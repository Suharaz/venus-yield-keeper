# Project Overview / PDR

## Goal
Qualify the campaign wallet for BNB Chain "Set and Earn" (1 Oct - 5 Nov 2026, 12:00 UTC) build requirement with a real yield agent.

## Requirements (from campaign rules)
- ERC-8004 identity on chain 97, owned by the campaign wallet, listed on a shortlisted marketplace (HelloFugu).
- Resolvable agent card at its registered domain stating purpose and category (`yield`).
- Live: answers when invoked (A2A `message/send`).
- >= 3 completed hires from 3 independent wallets (not owned or funded by the owner).
- >= 5 onchain actions on >= 3 UTC days, consistent with `yield` (Venus lending interactions).
- Public repo showing registry ID and chain.

## Non-goals
Mainnet funds, x402 payments, ERC-8183 seller flow (Pokter/Marque).
